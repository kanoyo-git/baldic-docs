# Справочник публичных контрактов

Эти страницы построены из metadata действительных source-built DLL. Они показывают объявленные public/protected типы и члены без загрузки игровых assemblies в CLR. Подписи принадлежат текущей поставке; `using`-alias не подменяет старые типы новыми.

Справочник показывает члены, объявленные непосредственно в типе. Унаследованные Unity/.NET-члены не дублируются; всё поведение наследования и стадий объясняется в учебных главах. Signature blocks — перечень контрактов, а не исходники, которые нужно целиком вставить в проект.

## Игровые модули

Для BB+ используйте [описание пятнадцати модулей](../api-bbplus/README.md) и соответствующие дочерние страницы справочника. Для BBCR — [восемь модулей](../api-bbcr/README.md). Типы, forwarded в общий Loader, описаны один раз в общих контрактах.

В reference включены и публичные служебные MonoBehaviour, нужные runtime. Их наличие в metadata не является рекомендацией вручную создавать Bootstrap/driver/patch-entry компоненты; используйте штатную установку, lifecycle и API.
