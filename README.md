# Baldic: руководство разработчика

[Читать онлайн](https://kanoyo-git.github.io/baldic-docs/).

Baldic загружает C#-моды в Unity Mono и даёт отдельные API для Baldi’s Basics Plus и Classic Remastered. Эта книга ведёт от установки до собственных предметов, меню, сохранений и IL-патчей.

| Часть | Назначение | Когда нужна |
|---|---|---|
| [Baldic Loader](loader/README.md) | Плагины, пакеты, конфиги, зависимости, стадии и владение ресурсами | Всегда |
| [Baldic Mixins](mixins/README.md) | Типизированные патчи, transpiler, доступ к закрытым членам и операции над IL | Когда готового API недостаточно |
| [API BB+](api-bbplus/README.md) | Контент и механики BB+ 0.14.5 | Мод для Plus |
| [API BBCR](api-bbcr/README.md) | Контент, стили, меню и механики BBCR 1.1 | Мод для Classic Remastered |

## С чего начать

- Хотите поставить готовые моды — начните с [установки](getting-started/installation.md).
- Пишете первый мод — пройдите [первый пакет](getting-started/first-mod.md), затем выберите API своей игры.
- Уже работали с BepInEx/Harmony — прочтите [совместимость и перенос](appendix/migration.md).
- Ищете точную сигнатуру — откройте [справочник](reference/README.md).
- Что-то не загружается — используйте [разбор ошибок](appendix/troubleshooting.md).

## Поддерживаемая версия

Книга описывает Loader **1.0.0**, Mixins на базе HarmonyX **2.9.0** и игровые API **0.0.1**. Целевые игры: **BB+ 0.14.5** и **BBCR 1.1**, Windows/Linux x64, **Unity Mono**. В манифестах BBCR используется нормализованная версия `1.1.0`.

Обычные BepInEx 5.4.x плагины и патчеры сохраняют DLL, пути и конфиги. Старые Baldic-моды, собранные с прежними публичными типами конфигов и патчей, нужно пересобрать. Новые примеры используют `Baldic.Loader` и `Baldic.Mixins`.

## Как устроена книга

Учебные главы объясняют порядок действий и ограничения. Справочник перечисляет контракты, извлечённые из реальных сборок: он помогает проверить перегрузку, но не заменяет объяснения жизненного цикла. Примеры относятся к игре, указанной в главе; одинаковое имя класса в BB+ и BBCR не делает сборки взаимозаменяемыми.

Для чтения сайта не нужны аккаунт, установленный .NET или GitBook. [Исходники книги и её публикация](appendix/hosting.md).
