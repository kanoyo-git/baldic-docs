# Ошибки и диагностика

Сначала сохраните `BepInEx/LogOutput.log` целиком и native Player.log. В сообщении важен первый сбой загрузки, его owner и stack trace; последующие dependency errors могут быть следствием.

| Симптом | Что проверить |
|---|---|
| Мод отсутствует в Mods | Каталог `mods`, корень ZIP, наличие манифеста, ID, выбор игры и dependency diagnostics |
| DLL не найдена | Совпадение manifest entry с AssemblyName и расположением файла рядом с manifest |
| `No [BaldicMod]` | Атрибут на выбранном entrypoint type; namespace и полное имя после `:` |
| `MissingMethodException` после обновления | Старый Baldic DLL в моде/его зависимостях; полная пересборка против одного SDK |
| Компилятор не находит ConfigEntry | Ссылка на fork `BepInEx.dll`, где находится собственный config namespace |
| Два определения AccessTools/CodeInstruction | Одновременные `using HarmonyLib` и `using Baldic.Mixins`; выберите тип границы явно |
| Тип игры/член не найден | BB+ SDK в BBCR или наоборот, версия игры, правильная перегрузка и private reflection |
| `registration barrier closed` | Новый участник зарегистрирован после Awake/startup; перенесите регистрацию раньше |
| Ассет `null`/prefab не найден | Стадия загрузки и правильное имя; не ищите game assets до готовности |
| Патч установлен, эффекта нет | Точная сигнатура target, выполняется ли метод, inlining, owner/priority и конфликт замен |
| UI или Unity object исчез после cleanup | В OwnObject передан заимствованный vanilla asset либо нарушен порядок восстановления |
| Изменение конфигов не видно | Ключ section/key, сохранение, перечитывание через existing entry, callback thread |
| AppImage не монтируется | Поддержка FUSE либо `--appimage-extract-and-run` |
| Linux не принимает клавиши | Сборка Linux, X11/Wayland окружение и ограничения текущего input patch |

## Что приложить к bug report

Укажите игру и её версию, ОС/архитектуру, версии Loader/API, имена и версии модов, действия до ошибки и полный лог. Для зависимостей важны манифесты, а для патча — target/callback signature и owner. Не публикуйте чужие сохранения или токены, если они не нужны для воспроизведения.

## Безопасный минимальный запуск

Создайте отдельную тестовую копию игры и новый профиль. Проверьте Loader без API, затем matching API и один мод, после — зависимости. Не удаляйте исходную установку или configs пользователя ради проверки.

Официальные `dev-run/game-test` создают disposable copies и оставляют компактный результат. Для Windows нужен Windows-депот игры: Wine с Linux Managed/data не проверяет Windows build. [Инструменты](../loader/tooling.md).

## Границы hot reload

Перезагрузка resource pack обновляет данные и подготовленные ассеты по транзакционному контракту. Она не выгружает DLL, не возвращает раннюю форму типа и не пересоздаёт автоматически весь ранее зарегистрированный контент. После замены исполняемого мода перезапустите игру.
