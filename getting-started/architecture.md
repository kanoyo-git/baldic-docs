# Как связаны Loader, Mixins и игровые API

Загрузчик запускается до обычных плагинов, проверяет игру, выбирает пакеты и готовит ранние преобразования. После создания Unity runtime он загружает плагины и C#-пакеты. Игровой API добавляет связи с конкретными классами игры и стадии подготовки контента.

```text
Unity Mono
  └─ Baldic Loader
      ├─ совместимые BepInEx плагины и патчеры
      ├─ C# пакеты mods/*.baldic
      ├─ Baldic Mixins: общий движок патчей
      └─ выбранный игровой API
          ├─ BB+ 0.14.5
          └─ либо BBCR 1.1
```

Установка Loader может работать без игрового API. Пакету, который использует только `Log`, `ModContext`, собственные события и mixins, не требуется зависимость от `baldic-api`. Работа с предметами, ассетами или фасадами игры требует соответствующих модулей API.

## DLL и пространства имён

| Файл в `BepInEx/core` | Контракты |
|---|---|
| `BepInEx.dll` | `Baldic.Loader.BasePlugin`, атрибуты плагинов, конфиги, журнал и пути; совместимые BepInEx-типы |
| `0Harmony.dll` | `Baldic.Mixins.Patcher`, аннотации, инструкции и reflection; совместимый HarmonyLib |
| `Baldic.Loader.dll` | `BaldicMod`, `ModContext`, `Mods`, события, пакеты, высокоуровневый `Mixin` |
| `Baldic.Loader.Preloader.dll` | Чистые контракты ранних преобразований |

Имя DLL и пространство имён не обязаны совпадать. Поэтому ссылка на один `Baldic.Loader.dll` не даёт компилятору тип `Baldic.Loader.Configuration.ConfigEntry<T>`: для него нужна совместимая `BepInEx.dll` из той же поставки.

## Два способа упаковать исполняемый код

**Пакет Baldic** — папка или ZIP с расширением `.baldic`, содержащий `baldic.mod.json`, собственные DLL и ресурсы. Он размещается в `mods/`, участвует в графе зависимостей и стадиях.

**Обычный плагин** — DLL в `BepInEx/plugins`, наследник `BasePlugin` с `[Plugin]`. Он получает Unity `Awake/Start/Update`. При необходимости плагин отдельно регистрируется в стадиях пакетов.

Не копируйте пакетный DLL в `plugins` одновременно с его `.baldic`: это два различных пути активации одного кода. [Пакеты](../loader/packages.md) · [Плагины](../loader/plugins.md).
