# Установка, обновление и удаление

Для игрока доступны автономный установщик Windows x64 и Linux AppImage. Устанавливать .NET для них не требуется. Нужна поддерживаемая копия выбранной игры с Unity Mono.

## Через установщик

1. Закройте игру. На Linux закройте Steam перед изменением его параметров запуска.
2. Запустите Windows EXE или сделайте AppImage исполняемым и откройте его.
3. Выберите BB+ или BBCR. Установщик ищет Steam-установки; можно указать папку вручную.
4. Выберите версию: по умолчанию последнюю стабильную, тестовые появляются по отдельной галочке.
5. Оставьте **Baldic API** включённым для игровых модов или отключите для Loader-only установки.
6. Установите Baldic и запустите игру.

Установщик скачивает выбранную поставку из GitHub Releases. Публичность документации не означает, что все описанные сборки уже опубликованы: если автор ещё не открыл релизы, используйте выданный им платформенный ZIP.

На Linux без FUSE можно запустить AppImage так:

```sh
chmod +x Baldic.Installer-1.0.0-x86_64.AppImage
./Baldic.Installer-1.0.0-x86_64.AppImage --appimage-extract-and-run
```

## Где лежат моды

```text
game/
  BepInEx/
    core/                    загрузчик и общие библиотеки
    plugins/                 обычные плагины
    patchers/                совместимые ранние патчеры
    config/                  настройки
  mods/
    baldic-api.baldic         выбранный API игры
    my-mod.baldic             пакет вашего мода
```

У BB+ и BBCR отдельные установки и отдельные игровые `.baldic`-сборки. Устанавливайте файл для нужной игры в её `mods/`; общий каталог для двух игр не настраивается. Управление модами в установщике не предусмотрено: файлы добавляются вручную.

Не распаковывайте API SDK в игровой `mods/`: SDK нужен разработчику, а в игре должен оставаться один выбранный API. Новые официальные пакеты выпускаются отдельно для каждой игры; старый формат `gameVariants` остаётся читаемым.

## Замена BepInEx и обновление

Установка сохраняет пользовательские плагины, конфиги и патчеры, проверяет поддерживаемую игру и хэши поставки. Заменяемые файлы получают проверяемую резервную копию; запись установки хранится в `BepInEx/Baldic.install.json`.

Откат на предыдущую версию разрешён после предупреждения. Он не пересобирает моды: их совместимость с выбранным API остаётся ответственностью автора мода. Выключенная галочка API оставляет уже установленный файл API и его версию без замены.

На Linux установщик настраивает Steam launch options и при удалении восстанавливает прежние. При ручном запуске из папки игры используется:

```sh
./run_bepinex.sh ./BALDI.x86_64
```

## Из платформенного ZIP

Распакуйте ZIP своей платформы, затем используйте включённые инструменты. Для Python-пути нужен Python; это не требование автономного GUI.

```sh
python3 /path/to/release/tools/baldic.py install "/path/to/game" --release /path/to/release
```

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\install-baldic.ps1 -GameDir "C:\Games\BALDI"
```

Параметры `--loader-only` и `-LoaderOnly` пропускают установку игрового API. Не копируйте содержимое `payload/` вручную поверх живой установки: штатный путь проверяет файлы и создаёт резервные копии.

## Удаление и восстановление

Закройте игру и выберите удаление в установщике. Оно работает офлайн. Для CLI:

```sh
python3 /path/to/release/tools/baldic.py restore "/path/to/game"
```

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\install-baldic.ps1 -GameDir "C:\Games\BALDI" -Restore
```

Не удаляйте запись установки и резервные копии до восстановления. Изменённые owned-файлы, повреждённые backups или неоднозначный сторонний startup target вызывают отказ; не обходите его ручным удалением журналов. [Диагностика](../appendix/troubleshooting.md).
